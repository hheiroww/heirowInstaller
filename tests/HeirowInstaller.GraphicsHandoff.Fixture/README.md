This helper prepares one signed, data-only fixture around a reviewed published primary host containing its declared DirectX 11 companion. It creates a fresh owned directory, one setup copy, a tiny HINST, and a generated fixture signing key. It starts no processes and performs no installation.

Build with an owned artifacts path, then run the helper with the published primary path, its exact SHA-256, and a fresh fixture directory. Review the prepared inputs and `fixture-invocation.json`; it records the exact executable, argument array, and environment for the windowless smoke. Launch with `UseShellExecute=false` and `CreateNoWindow=true`, applying its `DOTNET_BUNDLE_EXTRACT_BASE_DIR` override so primary extraction also stays in the fixture. The invocation requires isolation, no registration, the synthetic publisher pin and setup hash, and a separate owned `graphics-context` root for extracted companion files. The worker retains its own fresh `state` and `installed` directories.

The windowless smoke route requires the exact marked fixture, its own signed footer, fixed `notes.txt` bytes, and no executable entry point or integration modules. It runs the real DirectX 11 companion and original primary worker using machine scope with isolated paths, registration and launch disabled, then checks seven rejected worker protocol cases. It creates no installer/game windows, initializes no graphics device, requests no UAC, and retains its fixture payload, receipt, keys, and evidence for inspection. This route cannot accept a normal product package.
