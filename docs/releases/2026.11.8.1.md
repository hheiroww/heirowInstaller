# heirowInstaller 2026.11.8.1

Updating an installed application from a directly opened shared maintenance host
now reuses the installed receipt's verified standalone maintenance executable.
The small framework-dependent apphost is no longer mistaken for a native setup
with a signed product descriptor. Invalid or changed cached hosts remain rejected.

Self-updates launched through an installed native bootstrap recognize the signed
coordinator as the running application and retain its complete descriptor and
runtime bindings for the detached update helper.

The GPU interface enables Project-Z's shader desktop blur with a translucent
charcoal background. Cards, text and input controls remain sharp. Project-Z uses
an opaque background when capture is unavailable; the CPU wizard stays opaque.
No DWM or accent blur APIs are used.

This release uses the exact ProjectZ 2026.11.4.1 package, the latest published
Project-Z release at publication. The native application and website setup use
the shared maintenance and .NET archives instead of embedding another runtime.
