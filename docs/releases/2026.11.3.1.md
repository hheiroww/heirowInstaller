# 2026.11.3.1

Windows setup automatically opens a CPU-rendered compatibility wizard when
Project-Z cannot create its graphics device or initialize its native window.
The compatibility wizard supports installation, repair, and uninstall through
the existing installation controller, including signed package checks, license
and legal documents, optional features, destination selection, progress,
cancellation, and consent before closing applications.

Use `--software-rendering` to select CPU presentation directly. Automatic
fallback is limited to recognized graphics initialization failures before
content loading begins. It does not retry an installation or suppress package,
content, or application errors.

The desktop applications now use Project-Z `2026.11.2.2` by default.
