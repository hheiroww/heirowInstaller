# 2026.11.9.3

Fix machine-scope sparse updates from the installer workspace. The GUI sends the
`apply-files` operation to its privileged worker; the native promotion gate had
accepted `files` instead and rejected the valid request before installation.

The gate now uses the worker's actual operation name. Publisher signatures,
product/version identity, scope validation and prepared-stage checks remain
enforced. Regression coverage includes signed sparse metadata and rejection of
wrong operations, publisher, product, version and scope.
