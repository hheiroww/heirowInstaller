# Third-party notices

heirowInstaller uses Project-Z for its native Windows interface and SocketJack for heirowUpdater networking. Their licenses and transitive dependency notices apply separately from the heirowInstaller MIT license.

- [Project-Z](https://github.com/hheiroww/Project-Z), package `ProjectZ` 2026.11.4.1. The shared toolkit includes the exact package's `THIRD-PARTY-NOTICES.md` as `ThirdParty/ProjectZ-NOTICES.md`, plus its included font, shader and native component license texts under `ThirdParty/ProjectZ/2026.11.4.1/`.
- The native renderer uses [MonoGame](https://github.com/MonoGame/MonoGame) packages `MonoGame.Framework.Native` and `MonoGame.Runtime.Windows.DX12` 3.8.5.1. Project-Z's package notices describe its native components. Separate older WindowsDX builds can include SharpDX; that dependency is not part of the current shared toolkit.
- [SocketJack](https://github.com/hheiroww/SocketJack), package `SocketJack` 2026.10.25.1. The shared toolkit includes its exact package license as `ThirdParty/SocketJack-LICENSE.txt`.
- Transitive shipped packages include LibTessDotNet, Mono.Nat, SSH.NET, BouncyCastle.Cryptography and Microsoft.Extensions abstractions. `ThirdParty/dependencies.json` records the actual shipped package versions, dependency-lock content hashes, declared license expressions or file references, legacy license URLs and copied notice paths. Original NuGet `.nuspec` metadata and available license/notice texts are preserved under `ThirdParty/<package>/<version>/`. A license expression or URL is metadata, not a substitute license text invented by this project.
- LibTessDotNet 1.1.15 declares MIT in its NuGet metadata, while its matching upstream version's root and source notice is SGI Free Software License B 2.0. That original full notice is retained as `ThirdParty/LibTessDotNet/1.1.15/LICENSE.txt`. SSH.NET 2026.0.0's original MIT/Renci notice is retained as `ThirdParty/SSH.NET/2026.0.0/LICENSE`. The exact public upstream revisions, immutable source URLs and file hashes are recorded separately as `upstreamNoticeSources` in the dependency inventory; original package-declared metadata remains unchanged.
- The shared toolkit is framework-dependent. Its separate signed Microsoft .NET Windows Desktop runtime archives retain their official license and third-party notices. Self-contained builds include the runtime and its applicable third-party components. See the [.NET runtime license](https://github.com/dotnet/runtime/blob/main/LICENSE.TXT) and [third-party notices](https://github.com/dotnet/runtime/blob/main/THIRD-PARTY-NOTICES.TXT).

Imported MSI and EXE packages remain the original publishers' software. Importing does not change their license, account requirements, or redistribution rights. Specialized package workflows such as VSIX remain subject to their original installer contract.
